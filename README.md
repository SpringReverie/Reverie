# 孙嘉伟个人网站 · React + Vite

## 本地运行

```powershell
npm install
npm run dev
```

打开终端显示的本地地址（默认 http://127.0.0.1:5173）。这是 Vite 应用，需要通过开发服务器访问，不能直接双击 index.html。

## 构建

```powershell
npm run build
npm run preview
```

静态部署文件输出到 `dist/`。提交到 GitHub 的 `main` 分支后，Actions 自动构建并发布到 GitHub Pages。

线上地址：https://springreverie.github.io/Reverie/

## 修改内容

- `DESIGN.md`：本站「月夜观察手记」设计规范，参考 awesome-design-md 的 Oura 与 Mintlify 分析，规定中文标题、颜色、图文构图、长文阅读与独立手机适配。
- `src/reverie-design.css`：项目区与笔记页共享的设计变量；`src/projects-editorial.css` 提供主作品、次作品和笔记书签构图。
- `src/data.js`：个人资料、五种真实联系方式、项目和优势文案。
- `src/NotesApp.jsx` / `src/notes.css`：独立的笔记目录、全文搜索与纸面阅读版式。
- `scripts/sync-notes.mjs`：从本地 Obsidian 笔记库导出可公开内容；使用方法见 [笔记更新说明.md](./笔记更新说明.md)。后续双击「更新笔记并上线.cmd」即可同步新笔记并触发 GitHub Pages 发布。
- `src/mobile.css`：760px 以下的独立手机排版。摄影保留螺旋画廊并提供横滑选片，证书保留四排倾斜滚动墙与触摸柔光，联系方式采用手动滑动；电脑端保留原有展示。
- `src/App.jsx`：页面结构和交互。
- `src/styles.css`：1700px 版心、基础组件与响应式布局。
- `src/lunar-theme.css`：月夜蓝、柔白、淡紫色的正文视觉，宋体标题和轻盈的月光装饰。
- `public/assets/`：现有作品图片、头像、证书，以及本地视频。
- 首页视频：`public/assets/moonlit-drift.mp4`；封面：`moonlit-poster.jpg`。可替换同名文件，无需改代码。
- 原版页面备份：`public/legacy/index.html`。现有游戏保留，猫狗分类器目前通过原版页面体验，模型首次加载需要联网。

首页视频是本项目生成的缓慢星雾循环，支持暂停和减少动态效果设置。重新生成需要 Python 的 Pillow、NumPy 与 imageio-ffmpeg，然后执行 `python scripts/create-night-video.py`。原抽象轨道视频仍保留为可替换素材。

`src/TechText.jsx` / `TechText.css` 使用提供的标题代码，添加左对齐与后台停止绘制。首页标题支持轮廓显影、鼠标选字和拖动回弹；减少动态效果设置下关闭自动扫描。`src/MoonlightStudy.jsx` 提供同色系的新月与轨道装饰。

精选项目保留 3 个交互与 AI 项目，第四格是「学习笔记」入口，打开独立的 `notes.html` 阅读页；项目可按「知识手记」筛选。原有摄影专栏保持独立。

## 月球入场

- `src/MoonEntrance.jsx`：Three.js 月球、鼠标控制方向光、自然滚动过渡与渲染资源释放。
- `src/moon.css`：分层星空配色、大标题、175svh 滚动区间和正文淡入。
- `public/assets/moon-color.jpg` / `moon-height.jpg`：NASA SVS 月球表面与高程贴图，随项目一起本地提供。
- `moon-fallback.png`：不支持 WebGL 时展示的静态月球。素材来源见 `public/assets/MOON-CREDITS.md`。

向下滚动时月球缓缓缩小、退远并淡出，月光序章接续显现。星空包含 5200 个有远近层次的星点、轻微闪烁与鼠标视差。入场底部按钮、右上角联系方式和键盘导航也能进入正文。减少动态效果设置下取消月球缩放及文字位移。Three.js 按需加载，离开入场或切到后台时停止 GPU 绘制。

## 摄影与证书

- `src/MediaShowcase.jsx`：摄影编号索引、螺旋画廊和证书专栏。
- `src/InfiniteSpiral.jsx`：基于提供的代码实现摄影螺旋，支持自动播放、拖动、滚动和点击查看大图。
- `src/CertificateReels.jsx`：自行编写的四排倾斜轮播、鼠标/触摸柔光遮罩和滚动加速，不依赖 React Bits Pro。手机端缩小卡片、提高默认亮度并减慢自动速度，触摸结束后柔光淡出。
- `src/media.js`：9 张摄影作品和 17 张证书的统一编号与资源路径。
- 根目录摄影原片已统一命名为 `摄影作品01.jpg` 至 `摄影作品09.jpg`，改名前后映射记录在 `scripts/photography-renames.json`。
- `scripts/prepare-media.py`：使用 Pillow 生成摄影及证书的 WebP 大图与缩略图，原文件保留。输出在 `public/assets/photography/` 和 `public/assets/certificates/`。

两组画廊均可暂停，点击后支持左右箭头切换、Esc 关闭。离开屏幕或切换到后台会停止绘制，减少动态效果设置下关闭自动滚动。


## 章节动效

- `src/ScrollChapter.jsx`：十个章节、不同切景方式与右侧章节进度；桌面用 React Portal 将场景放在同一个 sticky 视口，原章节只提供滚动长度。
- `src/useChapterMotion.js`：保持原生滚轮输入，将每段阅读时间和下一段切景分开；舞台在同一视口内对齐，位置及元素显现逐帧缓动。几何信息在测量时缓存。
- `src/NarrativeScenes.jsx` / `src/sequenceMotion.js`：月光序言、月光碎片扩散和星光穿行，按滚动进度推进，向上滚动可倒回。过场使用本地 SVG 月光、细轨道和星座线，不复用摄影作品。
- `src/Observatory.jsx`：按需加载的真实 Three.js 作品观察台，以已有「星际躲避」封面为焦点，滚动推动相机从远景进入近景。
- `src/narrative-motion.css`：银蓝光圈、青蓝星廊、朦胧切景，以及向上和从左向右的直线覆盖。优势四张卡片错落翻入后进入联系方式。

月球开场 → 月光序章（三段文字在固定大小的光圈内切换，读完后光圈变色扩张、八片不同切面的微光棱片向四周散开）→ 正文首页 → 个人经历 → 星光穿行（彗星尾迹、星云光丝、稀疏星座与星尘错峰靠近，每个只经过一次）→ 朦胧光圈进入精选项目 → 向上覆盖进入 3D 作品观察台 → 从作品位置展开光圈进入摄影 → 横向切入证书与优势 → 向上覆盖进入联系方式。沿用夜蓝、柔白、淡紫与青蓝；没有复制参考站的绿色品牌视觉。

内容高度驱动章节长度，项目筛选和窗口变化会重新测量；窗口变化时尽量保留当前章节进度。长板块先完整展开，再切入下一段。导航采用连续滚动，可由后续滚轮操作打断。

共享视口内的场景位置保持不动，删除逐场景 sticky 加脚本位移补偿；滚动只更新内容推进与裁切。尺寸重测不再重置缓动，旋转文案等普通 DOM 更新不会触发全页测量。裁切使用 `overflow: clip`，避免按钮聚焦自动滚动内部舞台；桌面时间线关闭浏览器滚动锚定。背景切景移除整屏实时模糊，星尘速度与近处尺寸收敛，缓动收尾延长至约 145ms。

桌面宽度至少 980px 时启用章节舞台；较窄屏幕采用自然阅读与轻量入场，三段序言完整排列，3D 展示改为已有作品图片。系统开启“减少动态效果”时也使用静态阅读版。页面不在前台时停止章节和 3D 绘制，位置与入场收敛后不再连续绘制；WebGL 不可用时显示静态作品台。

摄影与证书的暂停、拖动及大图操作保持可用，没有新增动效库。

## 月夜观察手记版面

正文保留夜蓝、柔白和淡紫，通过不同构图形成章节层次：轨道方向入口、星图经历、一个主项目与两个错落项目、同步摄影手记、证书分类、优势证据入口和新月地平线。PC 版心最大 1700px；窄屏恢复自然滚动。

摄影编号选择会暂停并聚焦对应螺旋卡片；继续流动恢复自动轮播。清晰封面同步中心作品，点击可看原图。证书可按基础与训练、应用与工程、编程与工具筛选；分类中的预览保持原始证书编号。大图打开期间媒体轮播暂停。

后续资料入口：`src/journal-data.js` 中 `photoNotes` 保存编号对应的地点、时间与手记，`projectSupplements` 保存难点和下一步；空字段不会生成虚构信息。真实联系方式维护于 `src/data.js`。
## 月光拖尾与标题层级

鼠标拖尾基于提供的 GlowCursor / OGL 代码，使用柔白与淡蓝色、细光带和闲置淡出。仅精细指针且未启用减少动效时加载；页面隐藏或淡出完成后停止渲染，保留原生鼠标与按钮交互。拖尾只渲染轨迹附近区域。

TechText 被拖动的字使用挂载到 body 的固定顶层画布，避免两行画布边界及章节蒙版裁切。当前拖动的字优先绘制，松手后弹回；离开可见区域时清空浮层。

正文首页和联系页共用 LunarDisc，将 NASA 原始无光照月面纹理投影到球面，按表面法线与光源方向计算月相和亮度。暗面透明、明暗交界自然衰减，不再叠加圆形挖空和黑色渐变。两个月相只各生成一次并缓存，没有新增持续绘制的 3D 渲染器。联系页保留星座与地平线反射。

## 已补充的个人资料与滚动联系区

摄影 03、08、09 已加入用户提供的地点、日期与原句；其余照片保留普通画面说明，不显示待补充提示。星图经历新增 2026 年 9–10 月 RST 个人赛仿真机械鱼赛道参赛记录。三个小项目的“接下来”是编辑建议，没有作为已实现成果展示。

`src/ContactLoop.jsx` 使用提供的 LogoLoop 组件，横向循环展示微信、邮箱、QQ、电话、GitHub 五种真实联系方式。慢速流动、悬停缓停、暂停按钮和左右切换；账号可点击复制，邮箱、电话、GitHub 可直接打开对应链接。复制反馈由单独的状态区提示，键盘聚焦会让对应卡片可见；重复轨道不进入 Tab 顺序。

离开可见区域或切换后台时停止轮播绘制；系统减少动态效果时改为完整静态卡片列表。入口 3D 月球也降低环境光，以淡化暗面的纹理。

## 优势卡片的倾斜交互

`src/TiltedCard.jsx` 基于用户提供的 TiltedCard 和 `motion/react` 弹簧逻辑改为文本卡片：约 6° 的双轴倾斜、1.018 倍悬停缩放、轻微上浮与鼠标柔光。标题、图标和证据入口使用不同深度，保持月夜配色与原有内容。

外层 figure 负责章节入场，内层 article 负责鼠标弹簧，避免两种动效相互覆盖。离开卡片、移出屏幕或切换后台时回到初始状态；触摸输入和系统减少动态效果时保持静态。卡片中的项目、证书和摄影入口继续可用。

## 自然月相、椭圆公转与星空底

`src/OrbitingItems3D.jsx` 参考用户提供的椭圆旋转逻辑，以时间驱动的 requestAnimationFrame 更新四个方向和三颗小星的轨道。四个方向约 108 秒公转一周，大小与亮度随深度变化；悬停或键盘聚焦时缓停，首页的暂停控制同步暂停公转。移出屏幕、后台及系统减少动态效果时停止绘制。

全部正文使用 `public/assets/night-sky.svg` 的不规则星点、疏密变化和淡星云，配合原有章节位移形成轻微空间感。标题区保留视频云光，星空层共享缓存；卡片提高背景遮罩，保证文字易读。星空是原生 SVG，可用 `node scripts/create-night-sky.mjs` 重建。


## GitHub Pages 部署

参见 [GITHUB上线说明.md](./GITHUB上线说明.md)。上传 `src/`、`public/`、入口、npm 清单与锁文件、Vite 配置、`.github/workflows/deploy.yml`；GitHub Pages Source 选择 GitHub Actions。工作流自动读取仓库路径，运行 `npm ci` 和 Vite 构建，上传 `dist/`。`src/sitePath.js` 统一处理动态资源与项目链接的基础路径；CSS 和 HTML 中的资源路径由 Vite 构建转换。根目录 `index.html` 是 React 入口，生产页面为构建后的 `dist/index.html`。

转场图形维护在 `src/TransitFragments.jsx`：序章为不规则棱光薄片，穿行为彗星、轻纱光丝、星云、星座和星尘。固定种子、不同轮廓、不同出现时间与轨迹；穿行取消图形循环复用，反向滚动仍能沿原路径返回。没有增加外部图片、动画库或持续渲染器。

鼠标箭头使用 `src/LightPointer.jsx` 的柔白光圈替换，中心保留定位光点，与淡蓝拖尾配色衔接。可点击元素悬停时扩大，按下时收缩；圈体不接收事件，原有按钮、标题拖动与图片操作保持可用。精细指针启用，触摸不显示，减少动态效果时位置直接跟随且关闭弹性过渡。光圈进入浏览器顶层，打开大图弹窗后仍可见；离开窗口时隐藏并恢复系统鼠标，停驻后停止位置绘制。
